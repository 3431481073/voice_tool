### 1 · 声音 ← 物理麦克风（**无锚点**）

| 项 | 内容 |
| --- | --- |
| **是什么** | **物理麦克风**，经 `pyaudio`/PortAudio 采集。**不是程序间接口** |
| **拿了什么** | 16-bit PCM 单声道音频流（实际采样率见 [OUTPUT-SLOT.md](OUTPUT-SLOT.md) 第 3 项） |
| **拿来干嘛** | 实时读进内存 → 停止后写 `audio_temp\{时间戳}.wav` → 交给 faster-whisper 转写 |
| **假设** | ① 设备存在且未被独占<br>② **通路能真的交出音频** —— 本机实测过"整条通路返回数字静音而 `pa.open()` 不报错"（见 [deps.md](deps.md) 第八节）<br>③ 新开的流前面有约 **400ms 零填充**，判定前必须跳过 |
| **坏了会怎样** | **有自检层**：逐条探测 MME / DirectSound / WASAPI，识别死路并自动回退；全部不可用时弹"麦克风通路异常"并写日志。**不会静默录一路零** |

### 2 · 手指 ← 点击 / 全局热键（**无锚点**）

| 项 | 内容 |
| --- | --- |
| **是什么** | **人** —— 点悬浮球（`mouseReleaseEvent` → `controller.toggle()`）或按全局热键 |

| **坏了会怎样** | 热键不响应（可点悬浮球代替）· 或**少按一个键也误触发**（看门狗修掉，最多残留 0.3s） |
